# Meesho Mall Campaign Performance Dashboard

An automated campaign tracking and analytics dashboard for **Meesho Mall**, tracking performance across **Top Funnel** (Views, Likes, Comments), **Mid Funnel** (Auto-DM Activations & Clicks), and **Bottom Funnel** (Meesho Mall Orders & GMV).

## 🌟 Key Features

- **Month & Campaign Preceding Filter Hierarchy**: Select Month ➔ Select Campaign (including *All Campaigns*) ➔ Select Brand.
- **Master Spreadsheet View (Columns A–L)**: Live grid matching Google Sheets layout with CSV export.
- **Funnel Analytics & ROI Charts**: Interactive Plotly visualizations for social reach, engagement depth, DM conversion rates, and revenue.
- **Bulk Multi-Row Reel Submissions**: Interactive table editor (copy-paste from Excel) and batch text paste for adding creator reels.
- **Brands & Campaigns Manager**: Interface to register new Brands and define Campaigns with target KPIs and budgets.
- **👁️ External Viewer Report Mode**: Executive read-only mode for sharing reports with brand partners without edit options.

## 🚀 Getting Started & How to Run

### Prerequisites
- Python 3.9 or higher

### Installation
```bash
pip install -r requirements.txt
```

### Running the App
Run the following command in your terminal / PowerShell:

```powershell
python -m streamlit run app.py
```
*or using the Python Launcher:*
```powershell
py -m streamlit run app.py
```

Open your web browser at:
**`http://localhost:8501`**
